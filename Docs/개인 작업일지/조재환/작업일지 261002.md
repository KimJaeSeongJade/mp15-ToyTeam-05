## 막히거나 헤매었던 부분
- 음식을 Queue에 넣기는 했는데 음식을 빼낼 장소가 4곳이 있어 어떻게 순서를 돌아가며 빼야할지 헤맸었음
  음식 생성되는 곳이 상단 좌우, 하단 좌우 4곳으로 순서대로 1,2,3,4라고 생각할때
  1,4 / 2,3 에 순서대로 1,4 / 2,3 / 1,4 / ... 리스폰을 하려고 했는데 어떻게 리스폰을 해야할지 헤맸었음

  처음에는 int로 if문에서 %2 == 0 일때는 1,4 스폰 아닐때는 2,3 스폰으로 구현해볼까 싶었지만 
  지금 2번의 리스폰장소? 1,4 / 2,3 으로 고정되어 있어서 bool값으로 변경
  bool 값을 하나 주고 true일땐 1,4 false일때는 2,3에 생성하도록 구현하여 해결

  
- 막힌 것은 '막힘-> 현재 진행형' 이고 헤매었던 것은 막혔었으나 '현재 해결책을 찾은 것'입니다. 
- 막혔으나 해결책을 찾았다면 왜 헤매게 되었는지 + 어떻게 해결하였는지까지 적으면 좋을거같습니다.
