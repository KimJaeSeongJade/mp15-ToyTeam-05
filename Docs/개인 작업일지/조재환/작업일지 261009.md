## 막히거나 헤매었던 부분
- 조리 시간과 사운드 길이가 달라 재생 시간을 어떻게 맞춰야 할지 고민했음
  - 조리가 끝나도 사운드가 계속 재생되는 문제가 있어 조리 완료 시 사운드를 중지하도록 구현하려고 했음
  - 처음에는 SoundManager에서 Stop()을 호출하는 방식을 생각했지만, 조리기구 2개가 동시에 작동하는 상황에서 한쪽의 조리가 끝나면 다른 조리기구의 사운드까지 함께 멈추는 문제가 발생했음
  - 원인은 여러 조리기구가 SoundManager의 동일한 AudioSource를 사용하고 있었기 때문이었음
  - 이를 해결하기 위해 SoundManager에서는 짧고 단순한 효과음만 재생하도록 하고, 조리기구마다 개별 AudioSource를 추가하는 방식으로 변경함
  - 각 AudioSource의 Output을 AudioMixer의 SFX 그룹으로 설정하여 볼륨은 통합 관리하면서도 사운드는 개별적으로 제어할 수 있도록 구현함
  - 조리가 시작되면 해당 조리기구의 사운드를 재생하고, 조리가 끝나면 해당 AudioSource만 Stop()하도록 수정하여 해결함

- 타이틀 화면에서 BGM과 SFX 볼륨을 개별적으로 조절하는 기능을 구현하는 과정에서 어려움이 있었음
  - 기존에는 AudioSource를 통해 사운드를 재생하는 방식만 사용했기 때문에 AudioMixer를 처음 다뤄보게 되었음
  - AudioMixer의 그룹 설정과 슬라이더 값을 데시벨로 변환하는 방식에 대해 알아보며 구현함

- 다양한 상황에 맞는 효과음을 찾고 적절한 재생 타이밍을 설정하는 데 생각보다 많은 시간이 소요되었음

## 개인 회고록
- 처음에는 타이틀 화면에 Slider를 추가하고, 슬라이더 값을 0.2로 설정하면 각 AudioSource의 볼륨에 0.2를 곱해 기존 사운드의 20% 크기로 재생되도록 구현하려고 구상했음.
- 하지만 사운드 관련 정보를 찾아보면서 Master, BGM, SFX를 구분하여 볼륨을 관리할 때는 AudioMixer를 활용할 수 있다는 것을 알게 되었음.
- AudioMixer는 처음 접하는 기능이었고, 관련 정보를 찾아보면서 여러 블로그의 구현 방법을 확인했지만 생각보다 복잡해 보여 프로젝트 기간 내에 구현하기 어려울 수도 있겠다는 생각이 들었음.
- 이후 다른 블로그에서 비교적 간단하게 구현한 방법을 발견했고, 해당 내용을 참고하여 직접 구현하면서 기존에 작성했던 SoundManager 구조에 맞도록 수정해 기능을 완성할 수 있었음.
- 특히 AudioMixer를 활용한 사운드 설정 기능은 앞으로 개발할 프로젝트에서도 충분히 활용할 수 있고, 게임의 완성도를 높이는 데 도움이 되는 기능이라고 생각함.
- 따라서 이번 프로젝트가 종료된 후 개발일지를 정리하면서 AudioMixer의 구조와 동작 원리를 추가로 공부하고, 구현 과정까지 블로그에 정리해 두려고 함. 이를 통해 다음 프로젝트에서는 관련 기능을 더욱 빠르고 효율적으로 구현할 수 있도록 해야겠다고 생각했음.
