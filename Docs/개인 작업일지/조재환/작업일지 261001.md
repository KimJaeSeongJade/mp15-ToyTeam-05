## 막히거나 헤매었던 부분
- 처음에는 `IHoldable`에서 `FoodId`를 string으로 반환하도록 구현했다.
- 음식 조합을 구현하면서 ID뿐만 아니라 조합에 사용된 실제 Food 오브젝트를 제거하거나 제어해야 할 필요가 생겼다.
- `Food`와 `string`을 모두 사용할 수 있도록 제네릭을 활용하는 방법도 생각했지만, 구현 방법을 자세히 알아보기보다는 기능 완성을 우선하여 `Food` 타입을 직접 반환하도록 변경했다.
- 따라서 `FoodId` 대신 `FoodData`를 통해 Food 객체 자체를 반환하도록 변경하고, 필요한 경우 `FoodData.FoodId`로 ID에도 접근할 수 있도록 구현했다.

## 개인 회고록
- 처음에는 음식의 ID 값만 있으면 조합 기능을 구현하는 데 충분할 것이라고 생각했는데,
  실제로 Desk와 연결해보니 기존 음식 오브젝트를 삭제하거나 직접 제어해야 해서 Food 객체 자체가 필요했다.
- 제네릭을 사용하면 해결할 수 있지 않을까 생각했지만, 일단 기능을 완성하는 것을 우선으로 생각해 자세히 알아보지 않고 Food 타입으로 변경했다.
- 제네릭으로 구현이 가능할거 같은데 자세히 알아보지 않아 확장성을 막아둔게 아쉽다. 
- 시간이 나면 수정하고 다른 오브젝트들도 들고 사용할 수 있도록 넓혀야겠다
