## 막히거나 헤매었던 부분

- 기존에는 음식을 `Instantiate`로 생성하고 `Destroy`로 파괴하는 방식으로 구현되어 있어 이를 오브젝트 풀 방식으로 변경하려고 했다.
- 처음에는 음식 종류를 배열에 등록하고 각각 10개씩 미리 생성하는 것까지는 구현할 수 있었다.

- 하지만 이전에 사용해본 오브젝트 풀은 총알처럼 한 종류의 오브젝트만 관리하는 방식이었다. 이번에는 음식 종류가 여러 개였기 때문에 원하는 종류의 음식 Pool을 어떻게 구분하고, 해당 Pool에서 비활성화된 오브젝트를 가져올지 고민하게 되었다.

- 관련 정보를 찾아보던 중 골드메탈의 뱀파이어 서바이벌 제작 영상에서 여러 종류의 오브젝트를 Pool로 관리하는 방식을 참고하게 되었다.
- 해당 구조에서는 오브젝트 종류의 개수만큼 `List`를 만들고, 각 `List`가 한 종류의 오브젝트 Pool을 담당하도록 구성하고 있었다.
- 이를 음식에 적용하여 음식 종류별 `List<Food>`를 생성하고 `List<Food>[]` 형태로 관리하도록 구현하였다.

- 음식을 가져올 때는 요청받은 음식이 몇 번째 종류인지 찾아 해당 Pool에 접근하고, 그 안에서 비활성화된 오브젝트를 찾아 활성화하여 사용하도록 구현하였다.
- 또한 처음 생성한 10개의 오브젝트가 모두 사용 중인 경우에는 새로운 오브젝트를 생성하여 해당 Pool에 추가하도록 하여 필요한 경우 Pool의 크기가 자연스럽게 확장되도록 구현하였다.

- 기존에 생각했던 음식 생성 방식과 참고한 오브젝트 풀 구조를 합쳐 여러 종류의 음식을 하나의 `PoolManager`에서 관리할 수 있도록 해결하였다.
