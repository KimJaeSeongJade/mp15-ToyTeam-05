## 프로젝트 소개 - 제목과 컨셉
 - 여러분은 두 명의 정신없는 요리사입니다
 - 쉴 새 없이 나오는 재료들을 손질하고 요리하여 최고의 요리사가 되세요
 - 당신 옆의 사람은 협력하는 동료일 수도, 방해하는 경쟁자일 수도 있습니다

## 프로젝트 소개 - 설명
- 장르
	- 파티 게임 / 요리 시뮬레이션
- 플레이 타임
	- 루프당 3~5분
- 프로젝트 진행 기간
	- 9/30 ~ 10/12 (7일)
- 기획 의도
	- 모티브 - 오버쿡드의 재미요소를 참조
	- 여러개의 조리기구를 동시에 사용하며 방해효과와 기믹등으로 정신없는 상황속에서 음식을 만드는 재미를 느끼게 하는것이 목표

## 프로젝트 소개 - 게임 루프
- 요구하는 음식이 담긴 주문서가 나온다
- 벨트에서 재료가 나온다
- 이를 조리기구로 손질한다
- 손질한 재료를 탁자에서 합친다
- 완성된 음식을 카운터에 제출한다
- 주문서가 처리되고 점수를 획득
- 상대보다 높은 점수를 얻어 승리하거나 목표 점수를 달성하여 별을 획득

## 프로젝트 소개 - 프로젝트 목표와 일정
- 이 프로젝트를 하게 된 이유와 목적은 무엇인지
	- 단일 기기 환경에서의 멀티플레이 구현
	- 배운 내용을 토대로 오버쿡드의 기능들을 재현해보기
	- 협업 과정에서 발생할 수 있는 문제와 해결방법 확인
- 왜 오버쿡드인지
	- 기획에서 오버쿡드가 선정된 과정
	- 자작 게임이 아니라 레퍼런스 모작을 목표로 한 이유
- 모티브와의 차별점	
	- 캐주얼성?이 더 높은듯
		- 주문서 제한 시간이 없음
		- 접시와 설거지가 없음
		- 음식이 불타지 않음
	- 특별 주문과 방해 효과가 있음 (경쟁 모드)
		- PvP라는 특징을 잘 살릴만한 특성
