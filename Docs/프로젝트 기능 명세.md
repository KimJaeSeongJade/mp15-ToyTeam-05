# 프로젝트 기능 명세_290623


- 메인화면에서 게임시작 버튼을 누르면 게임 화면으로 넘어간다
- 게임화면에서 3의 카운트 이후 게임이 시작된다
- 게임 제한시간이 종료되면 결과 화면으로 넘어간다
- 결과 화면에서 재시작버튼을 누르면 메인 화면으로 돌아간다
- 결과 화면에서 종료버튼을 누르면 게임을 종료한다

# Player // 플레이어

## PlayerInput // 플레이어 입력

- 이동에 할당된 버튼을 누르면 8방향으로 이동한다
- 상호작용에 할당된 버튼을 누르면 앞의 물체와 상호작용을 시도한다

## PlayerInteract // 플레이어 상호작용

- 상호작용 버튼을 누르면 앞의 물체와 상호작용을 시도한다
- 범위 안에 (interface)IInteractable을 가진 물체와 상호작용 할 때 (interface)IInteractor를 전달한다

> IInteractable, IInteractor를 나눠서 구현하면,
> Interactable 쪽에서 Interactor에게서 기능을 호출할 수 있지 않을지?

### Hand // 플레이어 손

- 플레이어 손은 1칸의 공간을 가진다
- 플레이어 손이 비어있을때 IHoldable에 상호작용 하면 그 오브젝트를 들고 다닌다

## Player1 // 플레이어1

- W,A,S,D를 이동키로 사용한다
- G키를 상호작용키로 사용한다

## Player2 // 플레이어2

- 방향키를 이동키로 사용한다
- KeyPad0를 상호작용키로 사용한다

# PlayerInput // 플레이어 조작 담당 객체

> Input 담당 객체를 따로 두고, 1P, 2P에 대한 조작 자체를 객체로 만들어둔다.
> 같은 플레이어 캐릭터 프리팹으로 생성하되, 1P, 2P 조작 객체를 주입한다.

# Ingredient // 식자재 : 집을수있음(상호작용가능)

- 식자재는 정해진 레시피에 따라서 가공되어 음식이 될 수 있다
- 식자재를 들고 조리기구나 식자재가 있는 탁자에 상호작용 할 수 있다
    - 이때 알맞은 레시피가 있다면, 레시피에 따라 식자재를 가공한다

# Food // 음식 : 집을수있음(상호작용가능)

- 음식을 들고 알맞은 카운터에 상호작용하면 음식을 제출하여 점수를 얻는다

# CookWare // 조리기구 : 상호작용가능

- 상호작용 버튼을 일정시간 누르고 있거나(도마)
상호작용 후 일정시간이 경과하면(냄비) 가공이 완료된다
- 가공이 완료된 조리기구에 빈 손으로 상호작용 시 해당 IHoldable을 꺼낸다

# KitchenIsland // 탁자 : 상호작용가능

- 탁자는 1칸의 공간을 가진다
- 플레이어 손에 IHoldable이 있을때 탁자에 상호작용하면 그 오브젝트를 탁자에 올려 둔다
- 탁자위에 식자재가 있을때 알맞은 식자재를 들고 상호작용시 식자재를 가공한다

# TrashCan // 쓰레기통 : 상호작용가능

- 플레이어 손에 IHoldable이 있을때 쓰레기통에 상호작용하면 그 오브젝트를 풀로 돌려보낸다

# Belt // 벨트

- 일정 주기로 풀에서 식자재를 꺼내서 벨트에 올려놓는다
- 벨트에 올라간 식자재는 레일을 따라 이동한다
- 플레이어 손이 비어있을때 벨트 위의 식자재에 상호작용 할 경우 그 식자재를 들어올린다
- 레일의 끝에 도착한 식자재는 다시 풀로 돌아간다

# Counter // 카운터 : 상호작용가능

- 일정 시간이 경과하면 주문서를 풀에서 꺼낸다
- 일반주문서보다 긴 시간마다 주문서를 꺼내고 specialOrder를 true로 설정하여 특별주문서로 만든다
- 플레이어가 주문서에 해당하는 음식을 들고 알맞은 카운터에 상호작용 시 점수를 얻고 주문서는 풀로 돌아간다
- 주문서가 생성된 후 일정 시간이 경과하면 주문서가 풀로 돌아간다

# Order // 주문서

- 활성화 될때 해당하는 음식을 가지고 제한시간 코루틴이 시작된다
- 제한시간이 지나면 비활성화 상태로 OrderPool로 돌아간다
- specialOrder bool이 true면 특별주문서가 된다

## SpecialOrder // 특별 주문서 (주문서) (주문서 상속클래스로 사용 )

- 특별주문서는 시각적으로 일반 주문서와 구분 되어야 한다
- 특별주문서는 처리에 성공하면 일정시간동안 특수효과가 발동된다
- 특수 효과에는 다음과 같은 예시가 있다
1. 상대 플레이어의 화면을 먹물 UI로 일정 시간동안 가린다
2. 상대 플레이어의 재료 벨트가 멈춘다
3. 손에 소화기 오브젝트를 쥐어준다
    - 이 상태로 상호작용 버튼을 누를 경우 보고 있는 방향으로 소화기를 투척한다
    - 소화기가 플레이어와 충돌하면 플레이어는 일정시간 기절한다
    - 소화기가 플레이어와 충돌하거나 일정 거리를 날라가면 그 자리에 거품을 생성한다
    - 거품은 플레이어가 닿으면 일정시간동안 이동이 느려진다

# IngredientPool // 식자재 풀

- 식자재를 미리 생성해두고 비활성화 상태로 저장한다
- 식자재 요청시 풀에서 식자재를 반환한다 // 조리기구나 벨트
- 식자재가 들어올 시 다시 풀로 들어간다 // 조리기구나 벨트, 쓰레기통

# FoodPool // 음식 풀

- 음식을 미리 생성해두고 비활성화 상태로 저장한다
- 음식 요청시 풀에서 음식을 반환한다 // 조리기구
- 음식이 들어올 시 다시 풀로 들어간다 // 조리기구나 카운터, 쓰레기통

# OrderPool // 주문서 풀

- 주문서를 미리 생성해두고 비활성화 상태로 저장한다
- 주문서 요청시 풀에서 주문서를 반환한다 // 카운터
- 주문서가 들어올 시 다시 풀로 들어간다 // 카운터

# UI

- 메인 화면에는 다음과 같은 정보가 나타나야 한다
    - 게임 방법
    - 각 플레이어 조작키
- 게임 화면에는 다음과 같은 정보가 나타나야 한다
    - 남은 게임시간
    - 각 플레이어 돈 (점수)
    - 활성화 된 주문서
        - 카운터 번호
        - 요구하는 음식
        - 주문서 제한시간
        - 음식 가격
- 종료 화면에는 다음과 같은 정보가 나타나야 한다
    - 각 플레이어의 승패 여부
    - 각 플레이어가 획득한 점수
    - 각 플레이어가 제출한 음식의 갯수

# GameManager

- 게임이 시작되면 3초의 카운트 이후 제한시간, 돈 등의 데이터를 초기화 한다
- 제한시간이 종료되면 결과 화면으로 넘어간다


# GameData (SO)
- 게임 진행에 관련된 전반적인 데이터를 저장한다
- 시작 제한 시간
- 각 플레이어 돈
- 각 플레이어가 제출한 음식의 수
