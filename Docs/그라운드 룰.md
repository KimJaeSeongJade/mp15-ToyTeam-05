# 그라운드 룰

## 코어 타임

- **12 : 00 ~  23 : 00**
- 기본적으로 작업 가능 여부 상관없이 연락은 확인하기.
- 예외의 상황이 생길시엔 미리 알리기.

## 브랜치

- **Main 브랜치에서 작업 X**
- **[ 깃 허브 닉네임_ 진행중인 작업 ]** 한 눈에 확인가능하도록 **단어**로 표현한다.
- 작업 후 **해당 작업 완료 여부와 관계없이** 컴퓨터 종료 전 반드시 **PR 요청** 올린다.
- **PR**은 **저녁 22시까지** 보낸다.

## PR 확인

- PR 확인은 기본적으로 **팀장**이 맡아서 한다.
- PR 요청시 작업 내역은 확실하게 기입한다. ( 양식 가능하면 준비해보겠습니다_ 작업파트/ 내용/ 오류여부등 )
- PR 완료시 팀장님은 메신저에 해당 내용 간결하게 안내 남긴다.

## 작업 막혔을 때

- 30분 이상 막힌 부분에서 헤매고 있을 시 메신저를 통해 도움을 요청한다.
- 막힌 상황에 대해서는 가능한 명확하게 설명한다.

## 공유 문서 플랫폼

- 간단한 기획 → 구글 드라이브
- 팀 내 규칙 컨벤션 → 깃허브 저장소
- 회의록 → 깃허브 저장소
- 업무리스트 → 구글 시트
- 개인별 일정관리 캘린더 → 구글시트

## 컨벤션 및 커밋 메시지

- 커밋 양식 : 출처_ 교재

| **타입** | **언제 쓰나** |
| --- | --- |
| `[Feat]` | 새로운 기능 추가 |
| `[Fix]` | 버그 수정 |
| `[Docs]` | 문서 작성·수정 |
| `[Style]` | 동작 변화 없는 코드 정리 |

| `[Chore]` | 설정·패키지·에셋 등 잡업 |

## 기타 룰

- 처음 계획된 것과 다르게 **수정사항**이 생겼을 시 반드시 **모두에게 공유**합니다

          - 짧은 내용이라면 공지방에 공유, 내용이 많다면 문서화하여 ‘노션 or 시트에 링크걸기’ 합니다.

- 해야할 일이 많다면 **우선순위**를 확실하게 정하고 **한 번에 한 가지 일**을 합니다.

        - 한 사람이 2-3가지 일을 동시에 작업함으로서 일이 늦어지면 연결된 다른 사람 작업 진행도 함께 늦어              집니다. 또한 분담 가능한 일도 분담 할 수 없게 됩니다.
