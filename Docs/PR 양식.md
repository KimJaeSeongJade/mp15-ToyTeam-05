## [PR 양식]

## 어떤 일을 하였는가 *필수
- 이번 브랜치에서 어떤 일을 하였는지 가능하면 상세히 적습니다.

## 이슈 클로즈
- 닫을 이슈가 있다면 적습니다.

## 오류 유무 *필수
- 오류가 있는지 확인합니다. 있었다면 팀장님이 확인 할 수 있도록 상세히 적습니다.

## 특이사항 
- 해당 브랜치에서 구현한 기능에 대해 별도 전달사항이나 안내 사항이 있다면 적습니다.

## 화면
- 필요시 이미지를 추가해 이해를 돕습니다.

## 코드상 전달사항
- 다른 사람이 해당 코드에 대해 추가 작업을 이어가게 될 상황을 생각하며 코드관련 설명을 간략하게 적어줍니다. 

## 기타 룰
- PR 확인은 기본적으로 **팀장님**이 맡아서 합니다. (예외 상황은 늘 있습니다.)
- PR 완료시 팀장님은 메신저에 해당 내용 간결하게 안내 남깁니다.
- 위의 PR 양식은 모두 기입할 필요는 없습니다. 자유롭게 조절해 사용합니다.
